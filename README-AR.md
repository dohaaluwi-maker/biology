# BioBuddy — AI Chatbot for Biology Department

موقع محادثة ذكي لطلاب قسم البيولوجي، يعمل من متصفح الهاتف أو الكمبيوتر. يدعم العربية والإنجليزية، ويجيب من المعرفة العلمية العامة، ويمكن ربطه بمحاضرات القسم باستخدام File Search.

## ما الذي تحتاجينه؟
1. جهاز كمبيوتر (Windows أو Mac) لإعداد الموقع أول مرة.
2. حساب OpenAI API ومفتاح API صالح. اشتراك ChatGPT وحده لا يوفّر تلقائياً رصيد API؛ استخدام API تتم محاسبته بشكل منفصل.
3. Node.js إصدار 20 أو أحدث.
4. ملفات المحاضرات التي تريدين أن يعتمد عليها الروبوت (PDF أو DOCX أو PPTX أو TXT).

## التشغيل على جهازك
1. فكّي ضغط ملف المشروع.
2. افتحي مجلد `biology-chatbot`.
3. انسخي `.env.example` وغيّري اسم النسخة إلى `.env`.
4. افتحي `.env` وضعي مفتاح API بعد `OPENAI_API_KEY=`.
5. افتحي Terminal داخل مجلد المشروع ونفّذي:

```bash
npm install
npm start
```

6. افتحي المتصفح على `http://localhost:3000`.

## ربط محاضرات القسم
1. ضعي ملفات المحاضرات داخل مجلد `knowledge`.
2. من Terminal داخل مجلد المشروع نفّذي:

```bash
npm run knowledge
```

3. سيُنشئ البرنامج مكتبة للملفات ويطبع قيمة `VECTOR_STORE_ID`.
4. انسخي القيمة إلى ملف `.env` بهذا الشكل:

```env
VECTOR_STORE_ID=vs_...
```

5. أوقفي الموقع ثم شغّليه مرة أخرى باستخدام `npm start`.

إذا أضفتِ محاضرات جديدة لاحقاً، أعيدي تشغيل `npm run knowledge` ثم استخدمي معرّف المكتبة الجديد الذي يظهر في الطرفية.

## نشر الموقع ليستخدمه جميع الطلاب
المشروع جاهز للنشر على خدمة استضافة تدعم Node.js مثل Render أو Railway أو خادم الجامعة:
- ارفعي مجلد المشروع إلى مستودع GitHub خاص.
- أنشئي Web Service من المستودع.
- Build command: `npm install`
- Start command: `npm start`
- أضيفي متغيرات البيئة `OPENAI_API_KEY` و`OPENAI_MODEL` و`VECTOR_STORE_ID` من إعدادات الاستضافة، وليس داخل الكود.
- بعد نجاح النشر ستحصلين على رابط عام يفتحه الطلاب.

## ملاحظات مهمة
- لا تضعي مفتاح API في `public/` ولا ترسليه للطلاب.
- لا تشاركي ملف `.env` أو ترفعيه إلى GitHub.
- راقبي استهلاك API وضعي حدوداً للإنفاق من لوحة حساب API.
- الموقع الحالي لا يحتوي على تسجيل دخول للطلاب أو لوحة تحكم للمحاضرات. رفع المحاضرات في هذه النسخة يتم من مجلد `knowledge` عبر الأمر أعلاه.
- لا ترفعي بيانات شخصية أو ملفات طلابية حساسة إلى مكتبة المحاضرات.
- قد يخطئ الذكاء الاصطناعي؛ يجب مراجعة الإجابات العلمية المهمة مع المحاضرات والمدرسين.

## التقنيات
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- AI: OpenAI Responses API
- Course knowledge: OpenAI File Search / Vector Stores
